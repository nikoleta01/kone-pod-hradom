# Terra Incognita publicity logos

Drop the three mandatory logo files here (SVG preferred, otherwise PNG at 2x),
then list them in `src/components/publicity-logos.tsx`.

Check `Manual-publicity-2026.pdf` for:

- the exact logo files and their required minimum size
- the prescribed funding sentence and its wording per language
- whether a link back to terraincognita.sk is required

Until the files are added, the footer renders three dashed placeholders so the
missing block stays visible.
